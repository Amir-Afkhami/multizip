# multizip

A fast, efficient file compression command-line tool written in C++. 

Because life is too short to wait for files to compress.

---

## 🚀 Features

* **Blazing Fast:** Written in C++ to make sure your CPU actually breaks a sweat.
* **Simple CLI:** No bloated menus or confusing options—just straightforward commands.
* **Make-based Build:** Compiling is as simple as typing one word.
